🪔 Diya Animation in C++

About

A creative C++ program that generates a Diya using loops and a 2D character array.

Concepts Used

- C++ Programming
- Nested For Loops
- 2D Character Arrays
- Functions
- Animation using Time Delay

Features

- Draws the first half of a Diya.
- Automatically generates the remaining half.
- Creates a simple animation effect.

Language

C++
